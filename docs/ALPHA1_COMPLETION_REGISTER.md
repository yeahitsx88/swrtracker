## Classification and evidence rules

- **Verified complete** means the named bounded criterion has current proof; it does not accept a larger requirement automatically.
- **Implemented awaiting current verification** means source/tests implement the rule but a necessary current integrated or visual proof remains outstanding.
- **Approved incomplete** means an approved capability has an identified missing implementation; do not use this label merely for missing evidence.
- **Decision-blocked** means two materially different outcomes require an unresolved product decision. Only that path stops.
- **Superseded** means later authority explicitly replaces the old expectation.
- **Deferred** means outside the current approved development increment, including separately governed pilot/release work.
